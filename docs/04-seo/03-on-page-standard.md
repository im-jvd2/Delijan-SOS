# استاندارد سئوی درون‌صفحه‌ای (On-Page)

این سند برای **هر** صفحه‌ای که تولید می‌شود الزامی است. بدون رعایت آن، صفحه «تمام» محسوب نمی‌شود (بخش ۹ منشور).

---

## ۱. تایتل‌تگ (Title)

### ۱.۱ قواعد
| قاعده | مقدار |
|---|---|
| طول | ۵۰ تا ۶۰ کاراکتر (یا ≤ ۵۸۰ پیکسل) |
| جایگاه کلیدواژه | در **۲۵ کاراکتر اول** |
| جداکننده | ` \| ` |
| برند | در انتها |
| یکتایی | هیچ دو صفحه‌ای تایتل یکسان ندارند |

### ۱.۲ فرمول‌ها به تفکیک نوع صفحه

**صفحهٔ اصلی:**
```
امداد خودرو دلیجان | یدک‌کش، خودروبر و حمل به تعمیرگاه شبانه‌روزی 24 ساعته
```

**صفحهٔ خدمت:**
```
{خدمت} دلیجان | {تمایز} — امداد خودرو دلیجان
یدک‌کش دلیجان | شبانه‌روزی، اعزام سریع، هزینه پیش از حرکت — امداد خودرو دلیجان
حمل خودرو به تعمیرگاه دلیجان | 24 ساعته، قیمت پیش از اعزام — امداد خودرو دلیجان
```

**صفحهٔ شهری:**
```
امداد خودرو {شهر} | یدک‌کش و خودروبر شبانه‌روزی — امداد خودرو دلیجان
امداد خودرو نراق | یدک‌کش و خودروبر شبانه‌روزی — امداد خودرو دلیجان
```

**صفحهٔ جاده‌ای:**
```
امداد خودرو جاده دلیجان به {مقصد} | یدک‌کش 24 ساعته — امداد خودرو دلیجان
```

**نوشتهٔ مجله:**
```
{عنوان جذاب با عدد یا پرسش} | امداد خودرو دلیجان
هزینه امداد خودرو و یدک‌کش در 1405 | چه عواملی قیمت را تغییر می‌دهد؟ — امداد خودرو دلیجان
```

### ۱.۳ ممنوع در تایتل
- ❌ تکرار کلیدواژه: «امداد خودرو دلیجان | امداد خودرو دلیجان شبانه روزی»
- ❌ انباشته‌سازی: «امداد خودرو دلیجان - یدک کش دلیجان - خودروبر دلیجان - جرثقیل دلیجان»
- ❌ ایموجی بیش از یک مورد
- ❌ ALL CAPS یا علامت تعجب متعدد

> 📌 **تفاوت کلیدی ما با رقبا:** رقبای `emdadkhodro-delijan.ir` و `delijan-sos.ir` تایتل‌های انباشته دارند. تایتل تمیز و خوانا → **CTR بالاتر** حتی در رتبهٔ پایین‌تر.

## ۲. توضیح متا (Meta Description)

| قاعده | مقدار |
|---|---|
| طول | ۱۴۰ تا ۱۵۵ کاراکتر |
| ساختار | مزیت + تمایز + **فراخوان به اقدام** |
| شمارهٔ تماس | ✅ در توضیح متا بیاید (افزایش CTR در این صنعت) |
| یکتایی | اجباری |

### نمونه
```
صفحهٔ اصلی:
امداد خودرو دلیجان شبانه‌روزی ☎ 0910 050 4113 — یدک‌کش، خودروبر،
جرثقیل و حمل به تعمیرگاه در دلیجان و جاده‌های اطراف. قیمت پیش از اعزام.

صفحهٔ شهری (نراق):
امداد خودرو نراق شبانه‌روزی ☎ 0910 050 4113 — یدک‌کش و خودروبر در نراق و
مسیر دلیجان–کاشان. رسیدن سریع از پایگاه دلیجان. همین حالا تماس بگیرید.
```

> ⚠ گوگل گاهی توضیح متا را بازنویسی می‌کند. این ایراد نیست؛ هدف، **پوشش دادن** است نه کنترل مطلق.

## ۳. سلسله‌مراتب تیترها

### ۳.۱ قواعد ساختاری
- **یک `H1` در هر صفحه** — اجباری
- `H1` ≠ تایتل‌تگ (اما هم‌معنی)
- بدون پرش سطح: `H2 → H4` ❌
- `H2`ها بخش‌های اصلی؛ `H3`ها زیربخش
- کلیدواژه در `H1` و حداقل دو `H2`

### ۳.۲ الگوی H1

| نوع صفحه | الگوی H1 |
|---|---|
| صفحهٔ اصلی | `امداد خودرو دلیجان` |
| خدمت | `یدک‌کش دلیجان` / `حمل خودرو به تعمیرگاه دلیجان` |
| شهری | `امداد خودرو نراق` |
| جاده‌ای | `امداد خودرو جاده دلیجان به قم` |
| مجله | عنوان نوشته |

### ۳.۳ الگوی H2 برای صفحهٔ اصلی
```
H1  امداد خودرو دلیجان
H2  شماره امداد خودرو دلیجان — تماس ۲۴ ساعته
H2  خدمات امداد خودرو دلیجان
H2  چرا امداد خودرو دلیجان امداد خودرو دلیجان؟
H2  امداد خودرو جاده‌ای در مسیرهای دلیجان
H2  مناطق تحت پوشش امداد خودرو در دلیجان
H2  تعرفه خدمات امداد خودرو در دلیجان
H2  پرسش‌های پرتکرار
H2  نحوهٔ درخواست امداد (۳ گام)
```

## ۴. حجم و ساختار محتوا

| نوع صفحه | حداقل کلمه | هدف | ساختار |
|---|---|---|---|
| صفحهٔ اصلی | ۹۰۰ | ۱۲۰۰ | ۸ بخش |
| صفحهٔ خدمت | ۷۰۰ | ۹۰۰ | ۵–۶ بخش |
| صفحهٔ شهری | ۹۰۰ | ۱۲۰۰ | ۶ بخش + ۴ مورد محلی اجباری |
| صفحهٔ جاده‌ای | ۸۰۰ | ۱۱۰۰ | ۶ بخش + نقاط شاخص |
| نوشتهٔ مجله | ۸۰۰ | ۱۵۰۰ | بسته به موضوع |

### ۴.۱ قاعدهٔ «۱۰۰ کلمهٔ اول»
کلیدواژهٔ اصلی باید در **۱۰۰ کلمهٔ نخست** صفحه ظاهر شود — اما **یک بار**، نه سه بار.

### ۴.۲ پاراگراف‌ها
- حداکثر ۳ تا ۴ خط در موبایل (~۶۰–۸۰ کاراکتر)
- فهرست نقطه‌ای هر ۲۰۰–۳۰۰ کلمه
- حداقل یک جدول در صفحات خدمت و تعرفه

### ۴.۳ تراکم کلیدواژه
| هدف | ۰٫۵٪ تا ۱٫۵٪ |
|---|---|
| ❌ ممنوع | بالای ۲٫۵٪ |

> 📌 **قاعدهٔ کیفی:** اگر جمله‌ای را با حذف کلیدواژه هم می‌توان خواند، آن جمله طبیعی است. رقبای ما تراکم ۴–۶٪ دارند؛ این یک **مزیت** برای ماست.

## ۵. تصاویر

| قاعده | جزئیات |
|---|---|
| `alt` | توصیفی و فارسی، ۵ تا ۱۲ کلمه |
| ✅ نمونهٔ خوب | `یدک‌کش نیسان در حال حمل خودروی سواری در جاده دلیجان به قم` |
| ❌ نمونهٔ بد | `یدک کش دلیجان امداد خودرو دلیجان یدک کش` |
| نام فایل | انگلیسی، خط‌تیره، توصیفی: `yadak-kesh-nissan-delijan.webp` |
| فرمت | WebP |
| تعداد تصویر در صفحه | ۳ تا ۸ |
| تصویر شاخص | اجباری، ۱۲۰۰×۶۳۰ یا ۱۶:۹ |

> ⚠ **تصویر واقعی >> تصویر استوک.** عکس واقعی از ناوگان، هم سیگنال E-E-A-T است و هم در جست‌وجوی تصویر گوگل رتبه می‌گیرد.

## ۶. شمارهٔ تماس در صفحه

| قاعده | جزئیات |
|---|---|
| قالب نمایشی | ارقام فارسی، خوانا: `0910 050 4113` |
| لینک | `tel:+989100504113` |
| تعداد حضور | حداقل ۳ نقطه: هدر، بدنه، فوتر + نوار موبایل |
| در ابتدای صفحه | ✅ بلافاصله در Hero |
| کلیک‌پذیری | در موبایل با یک لمس |

```html
<a href="tel:+989100504113" class="btn-call" aria-label="تماس با امداد خودرو دلیجان">
  <span aria-hidden="true">📞</span> 0910 050 4113
</a>
```

## ۷. چک‌لیست یکتایی محتوا (ضد Thin Content)

هر صفحه پیش از انتشار این تست را پاس کند:

- [ ] حداقل **۳۰٪** محتوا مختص همین صفحه است (نه کپی از الگو)
- [ ] اگر دو پاراگراف متوالی را برداریم و در صفحهٔ دیگر بگذاریم، **معنی‌دار نیست** (یعنی واقعاً محلی است)
- [ ] حداقل **۲ نقطهٔ جغرافیایی واقعی** نام برده شده
- [ ] حداقل **۱ عدد واقعی** وجود دارد (فاصله، زمان، تعرفه)
- [ ] هیچ پاراگرافی عیناً در صفحهٔ دیگری تکرار نشده

> 🧪 **تست عملی:** ۳ جمله از متن را در گوگل داخل `" "` جست‌وجو کنید. اگر صفحهٔ دیگری از سایت خودتان پیدا شد → بازنویسی کنید.

## ۸. E-E-A-T برای سایت خدماتی

| سیگنال | پیاده‌سازی |
|---|---|
| **تجربه (Experience)** | عکس واقعی از مأموریت‌ها، توضیح «تیم ما در دلیجان مستقر است» |
| **تخصص (Expertise)** | توضیح فنی درست دربارهٔ باتری/دینام/یدک‌کشی |
| **اعتبار (Authoritativeness)** | مجوز/پروانه (اگر هست)، سال فعالیت، تعداد مأموریت، لینک‌های ورودی محلی |
| **اعتماد (Trust)** | آدرس، تلفن ثابت، حریم خصوصی، تعرفهٔ شفاف، سیاست لغو |

### ۸.۱ خط قرمزهای ادعا
| ❌ نگویید | ✅ بگویید |
|---|---|
| «ارزان‌ترین امداد خودرو دلیجان» | «قیمت شفاف و اعلام‌شده پیش از اعزام» |
| «نمایندگی رسمی ایران‌خودرو» | «پوشش خودروهای ایران‌خودرو و سایپا» |
| «کمتر از ۱۰ دقیقه می‌رسیم» | «معمولاً 10 تا 20 دقیقه در محدودهٔ شهری و 25 تا 45 دقیقه در جاده» |
| «تضمین ۱۰۰٪» | «تعهد به اعلام زمان و هزینه پیش از شروع کار» |
| «۱۰۰۰ مشتری راضی» (بدون مدرک) | آمار واقعی یا حذف ادعا |

> ⚠ **ریسک حقوقی:** ادعای کذب در خدمات اضطراری می‌تواند به شکایت منجر شود. ضمناً رقبای ما دقیقاً با همین ادعاها بی‌اعتمادی ایجاد کرده‌اند — صداقت، مزیت رقابتی ماست.

## ۹. الگوی کامل یک صفحهٔ خدمت

```
[H1] یدک‌کش دلیجان
[Hero] یک جمله ارزش + دکمهٔ تماس + شماره

[H2] شماره یدک‌کش دلیجان — تماس ۲۴ ساعته
     → بلوک تماس بزرگ (فقط `tel:` — بدون پیام‌رسان)

[H2] خدمات یدک‌کشی ما در دلیجان
     → جدول یا لیست: نیسان یدک‌کش / چرخگیر / کفی / جرثقیل

[H2] چه زمانی به یدک‌کش نیاز دارید؟
     → ۵–۷ سناریوی واقعی

[H2] یدک‌کش یا کفی خودروبر؟ کدام درست است؟
     → مقایسه (لینک به نوشتهٔ F6)

[H2] هزینهٔ یدک‌کش در دلیجان
     → عوامل مؤثر + لینک به /هزینه/

[H2] محدودهٔ پوشش یدک‌کش دلیجان
     → شبکهٔ لینک به صفحات شهری/جاده‌ای

[H2] پرسش‌های پرتکرار
     → ۵ سؤال با اسکیمای FAQPage

[CTA] نوار تماس پایانی
```
