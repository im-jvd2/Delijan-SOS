# تحلیل رقبا — ۹ رقیب واقعی

> **روش:** محتوای صفحهٔ اصلی (و در مواردی صفحات داخلی) هر رقیب مستقیماً بررسی شد. شمارهٔ تلفن‌ها، ساختار URL، پلتفرم و الگوی محتوایی **از خود صفحات استخراج شده‌اند**.
> ⚠ مواردی که **بررسی نشده‌اند** (سرعت واقعی، رتبهٔ فعلی، تعداد لینک ورودی) صریحاً با `⚠ بررسی‌نشده` علامت‌گذاری شده‌اند — این‌ها نیازمند ابزار بیرونی‌اند (`T-02` تا `T-05`).

## ۱. چهار رقیب معرفی‌شده توسط کارفرما

### 🥇 رقیب ۱ — `emdadkhodro-delijan.ir`
| ویژگی | مشاهده |
|---|---|
| تایتل صفحهٔ اصلی | «امداد خودرو دلیجان \| شماره جرثقیل شبانه روزی» |
| شماره‌ها | `08644223778` و `09187662551` |
| پلتفرم | سایت‌ساز استاتیک (مسیر تصاویر `/images/`، مسیر صفحات `/Page/{اسلاگ-فارسی}`) |
| ساختار | یک صفحهٔ اصلی بلند + ۴ صفحهٔ فرعی |
| صفحات فرعی | شماره جرثقیل دلیجان · مکانیک سیار دلیجان · یدک کش دلیجان · خودروبر دلیجان |
| محورهای پوشش | جاده دلیجان–سلفچگان، دلیجان–نراق، دلیجان–اصفهان، محور دلیجان–قم، مسیر دلیجان–ساوه |

**نقاط ضعف قابل استفاده:**
1. 🔴 **شمارنده‌های آمار با مقدار `۰` رندر می‌شوند** — در متن استخراج‌شده: «۰ گواهینامه‌ها / ۰ تعداد پروژه‌ها / ۰ مشتریان راضی / ۰ سال سابقه کار». این یعنی شمارنده‌ها با JavaScript پر می‌شوند و **خزنده عدد صفر می‌بیند**. سیگنال اعتباری منفی + نشانهٔ CWV ضعیف.
2. 🔴 **انباشت کلیدواژه:** جمله‌ای مثل «امدادگران امداد خودرو جاده دلیجان دلیجان در محل حاضر شده» — تکرار «دلیجان» داخل یک عبارت، نشانهٔ تراکم مصنوعی.
3. 🟡 **سایت‌ساز استاتیک** = بدون CMS، پس بدون بلاگ، بدون به‌روزرسانی، بدون اسکیم‌ای پویا.
4. 🟡 بخش FAQ با متن عمومی و غیرمحلی پر شده.
5. 🟡 دو شمارهٔ تماس متفاوت بدون توضیح نقش هرکدام → سردرگمی کاربر.

**نقاط قوت:**
- دامنهٔ Exact-Match با خط‌تیره
- تایتل بهینه با کلیدواژه در ابتدا
- فهرست محورهای جاده‌ای (الگوی خوبی است که ما کامل‌ترش می‌کنیم)

### 🥈 رقیب ۲ — `delijan-sos.ir`
| ویژگی | مشاهده |
|---|---|
| تایتل | «امداد خودرو دلیجان - شبانه روزی و سیار» |
| شماره | `09182020129` (تنها یک شماره) |
| پلتفرم | همان سایت‌ساز رقیب ۱ (`/Page/`, `/images/`) |
| ساختار | صفحهٔ اصلی بسیار بلند + صفحات فرعی |
| خدمات | یدک‌کشی سواری و سنگین، پنچرگیری، شارژ باتری، بازکردن درب، سوخت‌رسانی، جرثقیل، مکانیک سیار |

**نقاط ضعف:**
1. 🔴 **دیوار متنی:** پاراگراف‌های بسیار بلند بدون جدول، بدون فهرست، بدون تفکیک بصری → تجربهٔ کاربری و خوانایی ضعیف.
2. 🔴 **یک شمارهٔ تماس** = نقطهٔ شکست تک (اگر پاسخ ندهد، مشتری می‌رود).
3. 🟡 بدون جدول تعرفه.
4. 🟡 ادعاهای کلی بدون عدد («در سریع‌ترین زمان ممکن») — هیچ معیار اندازه‌گیری ندارد.
5. 🟡 نام دامنه با نام ما (`sos-delijan`) شباهت دارد → **دلیل اضافی برای خرید دفاعی** (فایل `../01-domain/01-domain-strategy.md`).

**نقاط قوت:** دامنهٔ کوتاه و به‌خاطرسپار؛ برند `delijan-sos` جا افتاده.

### 🥉 رقیب ۳ — `emdadkhodro1593.ir` (شبکهٔ ملی)
| ویژگی | مشاهده |
|---|---|
| تایتل | «خانه - امداد خودرو کشوری» |
| شماره‌ها | `02191306421`، پشتیبانی `09194331575`، `info@emdadkhodro1593.ir` |
| پلتفرم | **وردپرس + المنتور** (مسیر `/wp-content/uploads/`) |
| گستره | ملی — «در سراسر ایران» |
| دارایی‌ها | اپلیکیشن امدادگران + اپلیکیشن امدادخواهان، بلاگ فعال، فرم‌های پاپ‌آپ |
| الگوی محتوا | صفحات شهری/جاده‌ای انبوه: «امداد خودرو کرج»، «امداد خودرو ارومیه»، «امداد خودرو اتوبان ساوه سلفچگان»، «امداد خودرو اتوبان اراک به قم» |
| مزیت محتوایی | **جدول تعرفهٔ حمل منتشرشده** (درون‌شهری، برون‌شهری، کیلومتری) |
| صفحهٔ دلیجان | دارد (روی دامنهٔ دوم `emdadkhodro1593.com/emdadkhodro-delijan/`) با شمارهٔ `۰۸۶۹۱۰۱۱۵۹۳` |

**نقاط ضعف:**
1. 🔴 **محلی نیست.** یک شمارهٔ کشوری، بدون تیم محلی، بدون شناخت نقاط شاخص دلیجان.
2. 🔴 **دو دامنهٔ `.ir` و `.com` با محتوای مشابه** → ریسک محتوای تکراری و کانیبالیزیشن داخلی.
3. 🟡 صفحهٔ دلیجان روی `.com` است نه `.ir` — سیگنال ضعیف‌تر برای کوئری محلی.
4. 🟡 محتوای تبلیغاتی سنگین (طرح بیمهٔ حمل رایگان) که ارتباط محلی ندارد.

**نقاط قوت:** دامنهٔ قدیمی، اعتبار بالا، تولید محتوای سیستماتیک، **جدول تعرفه** (که باید ما هم داشته باشیم)، ساختار صفحات جاده‌ای که الگوی خوبی است.

### رقیب ۴ — `javani-emdadkhodro.com` (شبکهٔ استانی اصفهان)
| ویژگی | مشاهده |
|---|---|
| تایتل | «امداد خودرو اصفهان - امداد خودرو شبانه روزی 09130001250» |
| شرکت | شتاب گستر صدر جوانی |
| شماره‌ها | `03133653030`، `09130001250` |
| پلتفرم | **وردپرس** |
| اسلاگ | **لاتین** (`/covered-areas/delijan-car-assistance-service/`) |
| صفحات خدمتی | ۸ صفحه برای اصفهان: تعمیر در محل، مکانیک سیار، خودروبر، یدک‌کش، آپاراتی سیار، جرثقیل، بازکردن درب، تعمیر خودروی خارجی |
| صفحات شهری | ~۲۳ صفحه در هاب `/covered-areas/` — **شامل «امداد خودرو دلیجان»** |
| محتوا | جدول بزرگراه‌های اصفهان، بخش FAQ گسترده، لینک‌سازی داخلی قوی |

**نقاط ضعف:**
1. 🔴 **صفحهٔ دلیجان یک زیرصفحهٔ استانی است**، نه یک سایت محلی. محتوا عمومی است («دلیجان به عنوان سومین شهر صنعتی استان مرکزی») و **هیچ جزئیات واقعاً محلی ندارد** — نه محله، نه روستا، نه فاصله، نه زمان اعزام.
2. 🔴 شمارهٔ تماس اصفهانی است → برای کاربر دلیجانی سیگنال «غیرمحلی» می‌دهد.
3. 🟡 همهٔ صفحات شهری از یک الگوی متنی پیروی می‌کنند → شباهت محتوایی بالا.

**نقاط قوت:** لینک‌سازی داخلی عالی، اسلاگ لاتین (که ما هم انتخاب کرده‌ایم)، FAQ قوی، ساختار هاب‌واسپوک منظم.

> 💡 **مهم‌ترین یافته:** این رقیب **الگوی ساختاری** درستی دارد اما **عمق محلی** ندارد. استراتژی ما: همان ساختار + عمق محلی واقعی.

## ۴. تحلیل SWOT

### قوت‌ها (Strengths)
- دامنهٔ تازه اما **کاملاً مرتبط** و کوتاه
- تمرکز ۱۰۰٪ روی یک منطقه → امکان ساخت عمق محتوایی که شبکه‌های ملی نمی‌توانند جعل کنند
- استک فنی مدرن (وردپرس + المنتور پرو + هلو) → سرعت بالاتر از سایت‌سازهای استاتیک
- تیم کنترل‌کنندهٔ کل زنجیره (سئو + طراحی + محتوا) → کیفیت یکدست

### ضعف‌ها (Weaknesses)
- **دامنهٔ تازه = صفر اعتبار.** رقبای ۳ و ۴ دامنه‌های قدیمی با لینک ورودی دارند
- بودجهٔ محدود در برابر شبکه‌های ملی
- نبود سابقهٔ برند
- ⚠ اگر کارفرما مجوز رسمی نداشته باشد، ادعای اعتبار محدود می‌شود

### فرصت‌ها (Opportunities)
1. **صفحات جاده‌ای محلی** — فقط رقبای ملی دارند، آن هم بدون عمق محلی
2. **جدول تعرفهٔ شفاف** — فقط رقیب ۳ دارد، آن هم ملی و گیج‌کننده
3. **محتوای گردشگری دلیجان** (غار چال‌نخجیر) — هیچ رقیبی ندارد؛ منبع طبیعی لینک ورودی
4. **نقاط بدون آنتن‌دهی جاده** — محتوای منحصربه‌فرد و واقعاً مفید
5. **طراحی و سرعت** — همهٔ رقبا تجربهٔ کاربری ضعیفی دارند
6. **غلط املایی رقیب ۶** (`dilijan`) → ما با املای درست، سیگنال تطابق بهتری داریم

### تهدیدها (Threats)
- رقیب ۳ با تولید محتوای سیستماتیک می‌تواند صفحات دلیجان را گسترش دهد
- احتمال واکنش رقبای محلی (۱ و ۲) به ورود ما
- تغییر الگوریتم گوگل در ارزیابی سایت‌های تازه
- ریسک لینک‌سازی اسپم توسط رقبا در فضای محلی
