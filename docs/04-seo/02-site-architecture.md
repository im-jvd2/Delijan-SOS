## ۱. نمودار ساختار سایت

```
                              ┌──────────────┐
                              │   خانه  /    │  ← «امداد خودرو دلیجان»
                              └──────┬───────┘
        ┌──────────────┬─────────────┼─────────────┬──────────────┐
        ▼              ▼             ▼             ▼              ▼
 ┌────────────┐ ┌────────────┐ ┌──────────┐ ┌──────────┐ ┌──────────────┐
 │  خدمات     │ │  مناطق     │ │  جاده‌ها  │ │  مجله    │ │  تعرفه       │

       │              │             │            │
```

## ۳. سلسله‌مراتب محتوا در وردپرس

| نوع محتوا | پیاده‌سازی | چرا |
|---|---|---|
| هاب‌ها (`/خدمات/`, `/مناطق/`, `/جاده/`) | **برگه (Page)** | کنترل کامل با المنتور |
| صفحات خدمت | **برگه** زیرمجموعهٔ `/خدمات/` | کنترل کامل چیدمان |
| صفحات شهری | **برگه** زیرمجموعهٔ `/مناطق/` | ساختار یکنواخت و قابل تکثیر |
| صفحات جاده‌ای | **برگه** زیرمجموعهٔ `/جاده/` | — |
| نوشته‌های مجله | **نوشته (Post)** در دستهٔ «مجله» | آرشیو، خوراک، تازگی |
| تعرفه | **برگه** | — |

> ❌ **از Custom Post Type استفاده نکنید.** بدون بک‌اند و بدون نیاز به فیلتر/جست‌وجوی پیشرفته، CPT فقط پیچیدگی و بار اضافه می‌سازد.
> ⚠ اگر بعداً تعداد صفحات شهری از ۶۰ گذشت، مهاجرت به CPT + ACF/JetEngine بررسی شود — اما فقط در آن نقطه.

## ۴. استراتژی لینک‌سازی داخلی

### ۴.۱ قواعد
| قاعده | مقدار |
|---|---|
| لینک داخلی در هر صفحه | ۵ تا ۱۰ (محتوایی، نه فوتر) |
| فاصلهٔ از صفحهٔ اصلی | حداکثر ۳ کلیک |
| متن لنگر | توصیفی و حاوی کلیدواژهٔ طبیعی، **بدون تکرار یکسان در همه‌جا** |
| لینک به صفحهٔ والد | در breadcrumb و در متن |
| لینک‌های متقابل بین شهرهای همسایه | ✅ (مثلاً نراق ↔ جاسب ↔ دودهک) |
| لینک از مجله به صفحات تجاری | ✅ حداقل ۲ لینک در هر نوشته |

### ۴.۲ الگوی لنگر (تنوع اجباری)
برای صفحهٔ `/خدمات/یدک-کش-دلیجان/` این لنگرها **چرخشی** استفاده شوند:

| ✅ درست | ❌ غلط |
|---|---|
| یدک‌کش دلیجان | اینجا کلیک کنید |
| خدمات یدک‌کشی در دلیجان | اطلاعات بیشتر |
| اعزام یدک‌کش شبانه‌روزی | خدمات |
| یدک‌کش و خودروبر دلیجان | ادامه مطلب |

> ⚠ استفادهٔ ۱۰۰٪ از یک لنگر یکسان («یدک کش دلیجان») در ۴۰ صفحه، الگوی مصنوعی است و سیگنال منفی می‌دهد.

### ۴.۳ ماتریس لینک‌دهی صفحات شهری

هر صفحهٔ شهری این لینک‌ها را دارد:

```
┌─ به بالا:  خانه › مناطق تحت پوشش › [این شهر]
│
├─ درون‌متنی:
│   • ۲ لینک به صفحات خدمت (یدک‌کش، حمل به تعمیرگاه)
│   • ۱ لینک به صفحهٔ جادهٔ مرتبط
│   • ۲ لینک به شهرهای همسایه
│   • ۱ لینک به تعرفه
│
└─ بلوک «مناطق نزدیک»: شبکهٔ ۶ تا ۸ شهر همسایه (کمپوننت ثابت)
```

### ۴.۴ Breadcrumb
- فعال در همهٔ صفحات (به‌جز صفحهٔ اصلی)
- جداکننده: `›`
- با اسکیمای `BreadcrumbList` (فایل `06-schema-jsonld.md`)

## ۵. صفحاتی که ایندکس نمی‌شوند

| صفحه | دستور |
|---|---|
| نتایج جست‌وجوی داخلی | `noindex, follow` |
| آرشیو برچسب‌ها | `noindex, follow` |
| آرشیو نویسنده | `noindex, follow` |
| صفحهٔ حریم خصوصی و قوانین | ایندکس شود (برای اعتماد) — ولی از sitemap خارج |
| `staging.sos-delijan.ir` | `noindex` + Basic Auth + `Disallow` در robots |
| صفحات با وضعیت «پیش‌نویس» | خودکار ایندکس نمی‌شوند |
| `/هزینه/` | ✅ ایندکس شود (کلیدواژهٔ A7) |

## ۶. ساختار منوی اصلی

```
[لوگو]  خانه | خدمات ▾ | مناطق ▾ | امداد جاده‌ای | تعرفه | مجله     [📞 تماس فوری]
                 │            │
                 │            └─ دلیجان · نراق · محلات · سلفچگان · میمه · [همهٔ مناطق]
                 │
                 └─ یدک‌کش · خودروبر · چرخگیر · حمل به تعمیرگاه · حمل بین شهری · [همهٔ خدمات]
```

- حداکثر ۶ آیتم در سطح اول
- زیرمنو حداکثر ۶ آیتم + یک لینک «همه»
- **بدون مگامنو** (بار رندر و JS اضافه)

## ۷. ساختار فوتر

```
ستون ۱: لوگو + یک پاراگراف توصیفی (۳۰–۵۰ کلمه) + ساعات کاری
ستون ۲: خدمات — ۶ لینک
ستون ۳: مناطق — ۸ لینک + «مشاهدهٔ همه»
ستون ۴: تماس — تلفن (کلیک‌پذیر، تنها راه ارتباطی) · ساعت · محدودهٔ پوشش — ⛔ بدون پیام‌رسان، بدون آدرس، بدون ایمیل
نوار پایانی: © 1405 امداد خودرو دلیجان — حریم خصوصی · قوانین · نقشهٔ سایت
```

> ⚠ **فوتر با ۴۰+ لینک نسازید.** فوتر برای ناوبری ضروری است، نه برای پمپاژ لنگر.

## ۸. نقشهٔ سایت HTML

یک صفحهٔ `/نقشه-سایت/` (فارسی: «نقشهٔ سایت») ساخته شود که همهٔ صفحات را فهرست کند:
- برای کاربر (ناوبری)
- برای خزنده (کشف سریع)
- لینک از فوتر

> ⚠ این صفحه در sitemap XML نباشد (اختیاری).
