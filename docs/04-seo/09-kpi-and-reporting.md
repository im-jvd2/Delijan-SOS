**پیش از هر اقدامی**، این داده‌ها ثبت شوند. بدون خط‌پایه، هیچ پیشرفتی قابل اثبات نیست.

|---|---|---|
| تاریخ ثبت | — | |
| SERP برای ۲۰ کلیدواژهٔ P1 | جست‌وجوی دستی با IP ایران | |
| سایت فعلی (اگر هست) در GSC | Search Console | |
| لینک‌های ورودی فعلی | ابزار | |
| سرعت صفحهٔ فعلی | PageSpeed | |

## ۲. داشبورد KPI

### ۲.۱ شاخص‌های رتبه (هفتگی)
| کلیدواژه | هدف | ابزار |
|---|---|---|
| امداد خودرو دلیجان | صفحهٔ اول در ۶ ماه | Rank Tracker + GSC |
| یدک کش دلیجان | صفحهٔ اول در ۶ ماه | — |
| خودروبر دلیجان | صفحهٔ اول در ۶ ماه | — |
| حمل خودرو به تعمیرگاه دلیجان | ۳ صفحهٔ اول در ۹ ماه | — |
| جرثقیل دلیجان | صفحهٔ اول در ۶ ماه | — |
| ۱۰ کلیدواژهٔ جاده‌ای | ۳ صفحهٔ اول در ۹ ماه | — |
| ۲۰ کلیدواژهٔ شهری | ۳ صفحهٔ اول در ۱۲ ماه | — |

### ۲.۲ شاخص‌های ترافیک (ماهانه)
| شاخص | منبع |
|---|---|
| کلیک ارگانیک | GSC |
| نمایش (Impressions) | GSC |
| CTR میانگین | GSC |
| جایگاه میانگین | GSC |
| کاربران فعال | GA4 |
| صفحات فرود برتر | GA4 |

### ۲.۳ شاخص‌های تجاری (ماهانه) — **مهم‌ترین**
| شاخص | منبع |
|---|---|
| تعداد کلیک روی `tel:` | GA4 (`click_phone`) |
| ~~تعداد کلیک روی پیام‌رسان~~ | ⛔ حذف شد — تنها KPI تماس، `click_phone` است |
| **نرخ تماس** = تماس / کلیک ارگانیک | محاسبه |
| صفحات با بیشترین تماس | GA4 |
| تماس‌های واقعی (از لاگ تلفن کارفرما) | کارفرما |
| نسبت تماس‌های واقعی به تماس‌های ثبت‌شده | مقایسه |

> 💡 **این حلقهٔ بازخورد حیاتی است.** اگر صفحه‌ای ترافیک دارد ولی تماس نمی‌سازد، مشکل محتوا یا CTA است، نه سئو.

### ۲.۴ شاخص‌های فنی (ماهانه)
| شاخص | هدف |
|---|---|

| خطاهای ۴۰۴ | < ۵ در ماه |
| LCP موبایل (میدانی) | < ۲٫۵s در ۷۵٪ بازدیدها |

| به‌روزبودن پلاگین‌ها | ۱۰۰٪ |

## ۳. هدف‌های زمانی (واقع‌بینانه)

> ⚠ این‌ها **هدف** هستند نه **تعهد**. رتبه به رفتار رقیب و سرعت لینک‌سازی بستگی دارد.

| بازه | انتظار واقع‌بینانه |
|---|---|
| ماه ۱–۲ | ایندکس شدن، حضور در نتایج بلنددم، ترافیک ناچیز |
| ماه ۳–۴ | رتبه برای کلیدواژه‌های شهری کم‌رقابت، ۵۰–۲۰۰ کلیک/ماه |
| ماه ۵–۶ | صفحهٔ اول برای چند کلیدواژهٔ P1، ۳۰۰–۸۰۰ کلیک/ماه |
| ماه ۷–۹ | تثبیت در ۳ نتیجهٔ اول برای هسته، ۸۰۰–۲۰۰۰ کلیک/ماه |
| ماه ۱۰–۱۲ | رتبهٔ ۱–۳ در «امداد خودرو دلیجان»، ۲۰۰۰+ کلیک/ماه |

### عوامل شتاب‌دهنده
- لینک‌سازی محلی قوی در ۳ ماه اول
- ثبت در نقشه‌های ایرانی
- محتوای واقعاً محلی و یکتا
- سرعت برتر

### عوامل کُندکننده
- توقف تولید محتوا
- نبود لینک ورودی
- تغییرات مکرر ساختار URL
- هک یا بدافزار

## ۶. داشبورد کارفرما (Looker Studio)

یک داشبورد ساده با ۶ کارت:
1. کلیک ارگانیک ماهانه (نمودار خطی)
2. جایگاه ۵ کلیدواژهٔ اصلی (جدول)
3. تعداد تماس‌های کلیک‌شده (عدد بزرگ)
4. نرخ تماس (درصد)
5. LCP موبایل (عدد)
6. آپ‌تایم (درصد)

> 📌 **قاعده:** داشبورد باید در ۱۰ ثانیه قابل فهم باشد. کارفرما گزارش فنی نمی‌خواهد؛ می‌خواهد بداند «آیا دارد کار می‌کند؟».

---

## ۷. شفافیت با کارفرما

این جملات باید در جلسهٔ کیک‌آف صریح گفته و در صورت‌جلسه ثبت شوند:

1. **هیچ تضمین رتبه‌ای وجود ندارد** — گوگل الگوریتم خود را اعلام نمی‌کند.
2. **۳ ماه اول معمولاً نتیجهٔ قابل‌مشاهده‌ای ندارد** — این طبیعی است، نه شکست.
3. **توقف تولید محتوا = توقف رشد.**
4. **کیفیت تماس‌ها به پاسخ‌گویی کارفرما بستگی دارد** — سایت فقط تماس می‌سازد.
5. **هر وعدهٔ «رتبهٔ ۱ در یک ماه» از هر کسی، نشانهٔ کلاهبرداری است.**
