# سئوی محلی (Local SEO) — NAP، نقشه‌ها و سیگنال‌های جغرافیایی

> 📌 برای کسب‌وکار خدمات اضطراری محلی، **سئوی محلی مهم‌تر از سئوی محتوایی است.** گوگل برای کوئری‌هایی مثل «امداد خودرو دلیجان» ترکیبی از **ارتباط محتوایی** و **نزدیکی/اعتبار محلی** را رتبه می‌دهد.

---

## ۱. NAP — ستون فقرات سئوی محلی

**NAP** = Name, Address, Phone. این سه باید در **همه‌جا** یکسان و بدون حتی یک کاراکتر اختلاف باشند.

### ۱.۱ قالب استاندارد پروژه — ✅ نهایی (پس از Q-01 تا Q-36)

> 🔒 **منبع حقیقت این بلوک [`../05-content/nap-master.yaml`](../05-content/nap-master.yaml) است.**
> بلوک زیر **کپی همان فایل** است؛ اگر اختلافی دیدید، YAML معتبر است.

```yaml
name:
  display_fa: "امداد خودرو دلیجان"        # ✅ Q-01 — برند و نام نمایشی یکی است
  brand_en:   "Delijan SOS"
  tagline_fa: "24 ساعته در دلیجان و جاده‌های اطراف"   # ✅ Q-05
  legal_entity_fa: null                   # ❌ Q-02 — مجوزی برای نمایش وجود ندارد
  show_license_in_site: false             # ❌ Q-02
  founded_years: "بیش از 5 سال"           # ✅ Q-03 — فقط همین عبارت

address:
  has_physical_office: false              # ✅ Q-09 — خدمات سیار، دفتر ندارد
  street: null                            # ⛔ D-018 — آدرس منتشر نمی‌شود
  locality: "دلیجان"
  region:   "مرکزی"
  region_iso: "IR-MK"
  country:  "IR"
  postal_code: null
  public_statement_fa: "خدمات سیار — بدون پذیرش حضوری؛ در محل شما حاضر می‌شویم"

phone:
  primary:
    display: "0910 050 4113"              # ✅ Q-06 — رقم لاتین (Q-32)
    e164:    "+989100504113"
  alternate: []                           # ❌ شمارهٔ دوم وجود ندارد
  messengers: []                          # ❌ D-024 — فقط تماس تلفنی
  email: null                             # ❌ D-018 — ایمیل نداریم

geo:
  lat: 33.99028                           # ✅ مرکز دلیجان
  lng: 50.68361

hours:
  schema: "Mo-Su 00:00-23:59"             # ✅ Q-07 — 24 ساعته

price_range: null                         # ⛔ D-016 — هیچ نرخ/جدول قیمتی منتشر نمی‌شود
```

> ⚠ **سه اختلافی که در نسخهٔ اولیهٔ این بلوک بود و اصلاح شد:**
> 1. `phone_e164: "+989120000000"` — شمارهٔ placeholder بود؛ **شمارهٔ واقعی `+989100504113` است** (Q-06).
> 2. `address_line` و `postal_code` پر بودند — **کارفرما دفتر ندارد** (Q-09) و آدرس منتشر نمی‌شود (D-018).
> 3. `price_range: "$$"` — **هیچ نرخی منتشر نمی‌شود** (D-016)، پس در اسکیم‌ا هم نباید باشد.

### ۱.۲ قواعد سازگاری
| قاعده | درست | غلط |
|---|---|---|
| قالب تلفن | `0910 050 4113` در همه‌جا | `09120000000` / `۰۹۱۲-۰۰۰-۰۰۰۰` |
| نام | یکسان در هدر، فوتر، اسکیم‌ا، پروفایل‌ها | «امداد خودرو دلیجان» / «SOS دلیجان» / «امدادخودرو دلیجان» |
| آدرس | یک رشتهٔ ثابت | تغییر ترتیب یا مخفف‌سازی |
| املای شهر | «دلیجان» | «دلیجان/دلجان» |

> 🚨 **رایج‌ترین اشتباه سئوی محلی در ایران:** شمارهٔ تلفن در سایت با شمارهٔ ثبت‌شده در نقشه فرق می‌کند. گوگل این را سیگنال بی‌اعتمادی می‌گیرد.

## ۲. پروفایل‌های نقشه و فهرست‌های محلی

### ۲.۱ نقشه‌های ایرانی (اولویت بالا)
| سرویس | اقدام |
|---|---|
| **نشان (neshan.org)** | ثبت کسب‌وکار، دستهٔ «خدمات خودرو / امداد خودرو»، افزودن عکس، ساعات، تلفن |
| **بلد (balad.ir)** | ثبت کسب‌وکار، تکمیل همان NAP |
| سایر نقشه‌های بومی | در صورت وجود و اعتبار |

### ۲.۲ گوگل مپ / Google Business Profile
⚠ **واقعیت:** ثبت و تأیید کسب‌وکارهای ایرانی در Google Business Profile با محدودیت‌هایی همراه است (مسائل تحریم و فرایند تأیید). 
**اقدام عملی:**
- [ ] تلاش برای ثبت؛ در صورت موفقیت، ارزش بالایی دارد
- [ ] در صورت عدم امکان، **وقت پروژه روی آن قفل نشود** — تمرکز روی نشان/بلد + سیگنال‌های درون‌سایتی
- [ ] اگر کارفرما حساب تأییدشدهٔ قدیمی دارد، حتماً استفاده شود

### ۲.۳ فهرست‌ها و دایرکتوری‌ها
| نوع | نمونه |
|---|---|
| سایت‌های محلی دلیجان | پرتال شهرداری دلیجان، شورای شهر دلیجان، خبرگزاری‌های محلی استان مرکزی |
| دایرکتوری کسب‌وکار ایرانی | نیازمندی‌های معتبر، دایرکتوری‌های اصناف |
| انجمن صنفی | انجمن صنفی امداد خودرو کشور / استان مرکزی |
| تعمیرگاه‌های همکار | لینک دوطرفه با تعمیرگاه‌های معتبر منطقه |

> ⚠ **از دایرکتوری‌های بی‌کیفیت و «ثبت رایگان ۱۰۰۰ سایت» دوری کنید.** لینک اسپم، ضرر است نه سود.

## ۳. سیگنال‌های محلی درون‌سایتی

### ۳.۱ تگ‌های جغرافیایی (Geo Meta)
```html
<meta name="geo.region" content="IR-MK" />
<meta name="geo.placename" content="Delijan" />
<meta name="geo.position" content="33.9905;50.6816" />
<meta name="ICBM" content="33.9905, 50.6816" />
```
> ⚠ کد ISO استان مرکزی باید **تأیید شود** (T-07). اثر این تگ‌ها کم است اما بی‌ضررند و به درک ماشین کمک می‌کنند.

### ۳.۲ محتوای محلی واقعی
هر صفحه باید حداقل یکی از این‌ها را داشته باشد:
- نام محله/خیابان/روستا
- فاصله و زمان رسیدن
- نام جاده و نقاط شاخص
- نام منطقهٔ صنعتی یا جاذبه
- ارجاع به شرایط آب‌وهوایی محلی

### ۳.۳ بلوک «محدودهٔ پوشش» در صفحهٔ اصلی
یک بخش با دو ستون:
```
درون‌شهری دلیجان         |  مسیرهای برون‌شهری
──────────────────────  |  ──────────────────────
خیابان/محله ۱            |  جاده دلیجان–قم
خیابان/محله ۲            |  جاده دلیجان–اصفهان
شهرک صنعتی دلیجان        |  جاده دلیجان–اراک
…                        |  جاده دلیجان–کاشان
```
هر مورد برون‌شهری لینک به صفحهٔ جاده‌ای مربوطه.

### ۳.۴ نقشه در سایت
| گزینه | توصیه |
|---|---|
| iframe گوگل مپ | ❌ سنگین، احتمال مشکل دسترسی در ایران |
| نقشهٔ سبک «نشان» با بارگذاری تنبل | ✅ اگر API در دسترس باشد |
| **تصویر ایستا از نقشه + لینک** | ✅ **پیشنهاد اصلی** — سریع‌ترین و مطمئن‌ترین |

```html
<a href="https://neshan.org/…" target="_blank" rel="noopener"
   aria-label="مشاهدهٔ موقعیت امداد خودرو دلیجان روی نقشه">
  <img src="/wp-content/uploads/2026/09/naghshe-delijan.webp"
       width="1200" height="600" loading="lazy" decoding="async"
       alt="موقعیت پایگاه امداد خودرو دلیجان روی نقشه" />
</a>
```

## ۴. استراتژی نظرات (Reviews)

### ۴.۱ جمع‌آوری
| روش | اجرا |
|---|---|
| پیامک پس از اتمام خدمت | لینک مستقیم به صفحهٔ ثبت نظر |
| کارت QR داخل خودروی امداد | اسکن → لینک نظر |
| درخواست حضوری امدادگر | مؤثرترین روش |
| فرم سادهٔ درون‌سایتی | فقط نمایش؛ بدون تأیید جعلی |

### ۴.۲ قواعد
- ✅ فقط نظرات **واقعی** منتشر شوند
- ✅ نام کوچک + شهر + تاریخ
- ✅ پاسخ کوتاه و حرفه‌ای به هر نظر (حتی منفی)
- ❌ **هرگز** نظر جعلی ساخته نشود
- ❌ **هرگز** `aggregateRating` بدون نظر واقعی اضافه نشود → ریسک Manual Action

### ۴.۳ نمایش در سایت
یک بخش «نظرات مشتریان» در صفحهٔ اصلی با:
- ۳ تا ۶ نظر واقعی
- نام + شهر + تاریخ
- بدون ستارهٔ ساختگی اگر مدرک نداریم

## ۶. طرح‌وارهٔ ServiceArea (برای کسب‌وکارهای خدمات در محل)

اگر آدرس دقیق محرمانه است، در اسکیم‌ا از `areaServed` استفاده شود و `address` به سطح شهر محدود شود:

```json
"address": {
  "@type": "PostalAddress",
  "addressLocality": "دلیجان",
  "addressRegion": "مرکزی",
  "addressCountry": "IR"
},
"areaServed": [
  {"@type": "City", "name": "دلیجان"},
  {"@type": "City", "name": "نراق"},
  {"@type": "City", "name": "محلات"}
]
```

> ⚠ اگر آدرس فیزیکی واقعی ندارید (صرفاً سیار هستید)، صادقانه در سایت بنویسید «خدمات سیار — بدون پذیرش حضوری». گوگل برای «Service-area business» مدل مشخصی دارد و پنهان‌کاری نتیجهٔ معکوس می‌دهد.
