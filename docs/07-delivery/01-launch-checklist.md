# چک‌لیست لانچ — از پیش‌انتشار تا روز انتشار

> **قاعده:** هیچ‌کدام از بخش‌های زیر «اختیاری» نیست. اگر موردی قابل اجرا نبود، دلیل آن کتباً ثبت شود.

---

## بخش ۱ — پیش از انتشار (روی staging)

### ۱.۱ محتوا
- [ ] همهٔ صفحات P1 منتشر شده‌اند (۲۹ صفحه طبق `../05-content/02-page-inventory.md`)
- [ ] هیچ `Lorem ipsum` یا متن نمونه باقی نمانده
- [ ] شمارهٔ تماس واقعی در همه‌جا جایگزین placeholder شده
- [ ] آدرس واقعی یا صریحاً «خدمات سیار» ذکر شده
- [ ] همهٔ تایتل‌ها یکتا (بررسی با Rank Math)
- [ ] همهٔ توضیحات متا یکتا
- [ ] همهٔ H1ها یکتا و موجود
- [ ] هیچ صفحه‌ای زیر حداقل کلمات استاندارد نیست
- [ ] تست یکتایی محتوا (۳ جمله در گوگل) برای همهٔ صفحات شهری

### ۱.۲ سئوی فنی
- [ ] `robots.txt` درست
- [ ] sitemap تولید و قابل بازکردن
- [ ] canonical خوداشاره در همهٔ صفحات
- [ ] ۴۰۴ سفارشی فعال با کد HTTP درست
- [ ] همهٔ ریدایرکت‌ها `301` و بدون زنجیره
- [ ] Breadcrumb فعال با اسکیم‌ا
- [ ] همهٔ JSON-LD در Rich Results Test بدون خطا
- [ ] `noindex` روی staging فعال است
- [ ] صفحات جست‌وجو/برچسب/نویسنده `noindex`

### ۱.۳ سرعت
- [ ] PageSpeed موبایل ≥ ۹۰ (یا دلیل مستند)
- [ ] LCP < ۲٫۵s در تست Fast 4G
- [ ] CLS < ۰٫۱
- [ ] وزن صفحهٔ اصلی ≤ ۱٫۲MB
- [ ] تعداد درخواست‌ها ≤ ۶۰
- [ ] LiteSpeed Cache فعال (`x-litespeed-cache: hit`)
- [ ] همهٔ تصاویر WebP با ابعاد صریح
- [ ] فونت preload شده و زیرمجموعه‌شده
- [ ] هیچ Google Font بارگذاری نمی‌شود

### ۱.۴ امنیت
- [ ] SSL معتبر، SSL Labs گرید A
- [ ] `DISALLOW_FILE_EDIT` فعال
- [ ] 2FA روی همهٔ کاربران
- [ ] نام کاربری `admin` وجود ندارد
- [ ] XML-RPC غیرفعال (اگر استفاده نمی‌شود)
- [ ] مجوز فایل‌ها درست
- [ ] پلاگین nulled نصب نیست
- [ ] بکاپ کامل پیش از لانچ گرفته شده

### ۱.۵ تجربهٔ کاربری
- [ ] تست روی Chrome، Firefox، Safari (iOS)، Samsung Internet
- [ ] تست روی ۳۶۰px، ۳۹۰px، ۷۶۸px، ۱۰۲۴px، ۱۳۶۶px
- [ ] هیچ سرریز افقی وجود ندارد
- [ ] همهٔ دکمه‌های `tel:` کار می‌کنند (تست روی موبایل واقعی)
- [ ] ⛔ لینک پیام‌رسان وجود **ندارد** (بازنگری Q-08) — فقط `tel:` تست شود
- [ ] منوی موبایل با کیبورد هم قابل استفاده است
- [ ] نوار چسبان موبایل روی محتوا نمی‌افتد
- [ ] فوکوس قابل مشاهده
- [ ] کنتراست همهٔ متن‌ها ≥ 4.5:1

### ۱.۶ حقوقی و اعتماد
- [ ] صفحهٔ حریم خصوصی منتشر
- [ ] صفحهٔ قوانین منتشر
- [ ] هیچ ادعای غیرمستند در سایت نیست (بازبینی دروازهٔ ۴)

## بخش ۵ — برنامهٔ بازگشت (Rollback)

### چه زمانی بازگردیم؟
| شرایط | اقدام |
|---|---|
| سایت بیش از ۳۰ دقیقه در دسترس نیست | بازگشت فوری |
| خطای ۵۰۰ گسترده | بازگشت فوری |
| SSL کار نمی‌کند و قابل رفع سریع نیست | بازگشت فوری |
| مشکل ظاهری جزئی | ❌ بازنگردید — در محل رفع کنید |

### مراحل بازگشت
```
۱. اطلاع به کارفرما (یک پیام کوتاه و شفاف)
۲. بازگرداندن رکوردهای DNS به مقدار قبلی
۳. یا بازیازی فایل‌ها/دیتابیس از بکاپ پیش از لانچ
۴. پاک‌کردن کش
۵. تست
۶. ثبت حادثه + علت ریشه‌ای
۷. برنامه‌ریزی دوباره برای لانچ
```

> 📌 **پیش‌نیاز:** بکاپ پیش از لانچ باید **تست‌شده** باشد، نه فقط گرفته‌شده.

## بخش ۶ — معیارهای «لانچ موفق»

لانچ وقتی موفق است که:
1. سایت با HTTPS و بدون هشدار بالا باشد
2. همهٔ صفحات P1 قابل دسترسی و بدون خطا باشند
3. تماس تلفنی از موبایل واقعی کار کند
4. LCP زیر ۲٫۵ ثانیه باشد
5. سایت در GSC ثبت و sitemap ارسال شده باشد
6. ۷۲ ساعت آپ‌تایم ۱۰۰٪
7. کارفرما تأیید کتبی داده باشد
