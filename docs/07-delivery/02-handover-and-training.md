## ۲. انتقال مالکیت — گام‌های اجباری

### ۲.۱ دامنه
1. اگر شناسهٔ مالک به نام ماست → انتقال رسمی در پنل ایرنیک به شناسهٔ کارفرما
2. تغییر ایمیل مدیریتی، فنی و پرداخت به ایمیل کارفرما
3. تحویل رمز عبور + **تغییر آن توسط کارفرما**
4. تحویل رسید پرداخت و تاریخ انقضا

### ۲.۲ هاست
1. تغییر ایمیل حساب به ایمیل کارفرما
2. تغییر رمز عبور
3. تغییر اطلاعات پرداخت به کارت کارفرما
4. فعال‌سازی تمدید خودکار

### ۲.۳ وردپرس
1. ساخت کاربر مدیر کل جدید برای کارفرما
2. حذف یا تنزل نقش کاربر ما به «نویسنده» (یا حذف کامل اگر پشتیبانی نداریم)
3. کارفرما رمز همهٔ کاربران را تغییر دهد

### ۲.۴ صورت‌جلسهٔ تحویل
یک سند با این محتوا، امضاشده توسط هر دو طرف:
```
تاریخ تحویل: …
تحویل‌دهنده: …
تحویل‌گیرنده: …

اقلام تحویل‌شده: [فهرست بالا با تیک]
وضعیت سایت در لحظهٔ تحویل:
  - نسخهٔ وردپرس: …
  - نسخهٔ پلاگین‌ها: [فهرست]
  - تاریخ آخرین بکاپ: …
  - رتبهٔ فعلی کلیدواژه‌های اصلی: …
  - ترافیک ماهانه: …
موارد باقی‌مانده: …
دورهٔ گارانتی: …
```

## ۴. راهنمای سریع کارفرما (۱ صفحه — قابل چاپ)

```
════════════════════════════════════════════════════════
   راهنمای سریع مدیریت سایت امداد خودرو دلیجان
════════════════════════════════════════════════════════

ورود:  https://sos-delijan.ir/wp-admin
کاربر: ……………………
رمز:   (در Vault)

────────────────────────────────────────────────────────
۱. تغییر شمارهٔ تماس
   المنتور → قالب‌ها → هدر → ویرایش با المنتور → شماره را عوض کنید
   ⚠ شماره در ۴ جا هست: هدر، فوتر، صفحهٔ تماس، نوار موبایل
   ⚠ حتماً هر ۴ جا را عوض کنید

────────────────────────────────────────────────────────
۲. افزودن نوشتهٔ مجله
   نوشته‌ها → افزودن → عنوان → متن → تصویر شاخص
   سپس در سمت راست: تایتل سئو و توضیحات متا را پر کنید
   انتشار → تمام

────────────────────────────────────────────────────────
۳. افزودن صفحهٔ شهری جدید
   برگه‌ها → افزودن → عنوان: «امداد خودرو {شهر}»
   در قسمت «قالب» → P-City را انتخاب کنید
   جعبهٔ اطلاعات محلی را پر کنید
   ⚠ اگر فاصله و زمان واقعی را نمی‌دانید، صفحه را منتشر نکنید

────────────────────────────────────────────────────────
۴. به‌روزرسانی
   پیشخوان → به‌روزرسانی‌ها
   ⚠ اول بکاپ بگیرید
   ⚠ همه را هم‌زمان به‌روز نکنید؛ یکی‌یکی
   ⚠ پس از به‌روزرسانی، سایت را چک کنید

────────────────────────────────────────────────────────
۵. ❌ این کارها را نکنید
   ✗ نصب پلاگین ناشناس
   ✗ حذف پلاگین‌های فعال بدون مشورت
   ✗ تغییر «پیوندهای یکتا»
   ✗ تغییر آدرس سایت در تنظیمات
   ✗ غیرفعال کردن SSL
   ✗ پاک کردن بکاپ‌ها

────────────────────────────────────────────────────────
۶. 🆘 در صورت مشکل
   ۱) چیزی را تغییر ندهید
   ۲) اسکرین‌شات از خطا بگیرید
   ۳) با پشتیبانی تماس بگیرید: ……………………

۷. 📅 یادآوری‌ها
   تمدید دامنه:  ……………………
   تمدید هاست:    ……………………
   تمدید المنتور: ……………………
════════════════════════════════════════════════════════
```
