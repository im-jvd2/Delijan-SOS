# مرحلهٔ ۲ — کدنویسی UI با دادهٔ واقعی (الگوی کار)

> 🎯 **الگوی کار — مطابق بازنگری کارفرما (1405-06-25) / D-023**
>
> سایت نهایی در **المنتور** ساخته می‌شود. این مرحله یک «پروتوتایپ تزئینی» نیست؛
> **خروجی این مرحله همان چیزی است که کارفرما از رویش در المنتور طراحی می‌کند.**
>
> ```
> ما: UI را با HTML/CSS و «دادهٔ واقعی» کدنویسی می‌کنیم
>        ↓
> کارفرما: همان چیدمان را در المنتور بازسازی می‌کند (الگوبرداری، نه اختراع مجدد)
> ```
>
> **پیامد مهم:** چون این کد «منبع الگو» است، هیچ دادهٔ ساختگی/لورم در آن مجاز نیست.
> شمارهٔ تماس، فاصله‌ها، نام شهرها، متن دکمه‌ها و اسکیم‌ا همه **واقعی** هستند.
>
> **پس این مرحله ۲۸ «تصمیم» نیست — ۵ تحویل‌دادنی است.** گام‌های ۴۱ تا ۶۸
> زیرمجموعهٔ این ۵ تحویل‌دادنی‌اند و شماره‌شان فقط برای ارجاع حفظ شده.
