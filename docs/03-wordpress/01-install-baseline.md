# نصب و پیکربندی پایهٔ وردپرس

---

## ۱. نصب

### روش پیشنهادی: WP-CLI
```bash
cd ~/public_html
wp core download --locale=fa_IR
wp config create --dbname=sosdelij_wp --dbuser=sosdelij_dbu \
  --dbpass='<رمز>' --dbhost=localhost --dbcharset=utf8mb4 --dbcollate=utf8mb4_unicode_520_ci
wp core install --url="https://sos-delijan.ir" \
  --title="امداد خودرو دلیجان" \
  --admin_user="<کاربر>" \
  --admin_password="<رمز قوی>" \
  --admin_email="<ایمیل مدیریتی پنهان>"
# ⚠ ایمیل مدیریتی فقط برای بازیابی رمز است و هرگز در سایت نمایش داده نمی‌شود.
# کارفرما ایمیل سازمانی روی دامنه ندارد (Q-20 / D-018).
```

### روش جایگزین: Softaculous در کنترل پنل
قابل قبول است، اما **حتماً** پس از نصب:
- [ ] حذف فایل‌های نمونه
- [ ] حذف پلاگین‌های نصب‌شدهٔ خودکار که لازم نداریم
- [ ] تغییر نام کاربری `admin` (اگر Softaculous آن را ساخت)

## ۲. سخت‌کردن `wp-config.php`

این خطوط **پس از** خطوط موجود اضافه شوند (پیش از `/* That's all, stopping editing! */`):

```php
/* --- URL رسمی --- */
define('WP_HOME',    'https://sos-delijan.ir');
define('WP_SITEURL', 'https://sos-delijan.ir');

/* --- امنیت --- */
define('DISALLOW_FILE_EDIT', true);      // حذف ویرایشگر فایل در پیشخوان
define('DISALLOW_FILE_MODS', false);     // نصب افزونه از پیشخوان مجاز (در تولید می‌توان true کرد)
define('WP_AUTO_UPDATE_CORE', 'minor');  // به‌روزرسانی امنیتی خودکار
define('AUTOMATIC_UPDATER_DISABLED', false);
define('WP_POST_REVISIONS', 5);          // محدودسازی رونوشت‌ها
define('EMPTY_TRASH_DAYS', 15);

/* --- کش --- */
define('WP_CACHE', true);                // فقط پس از نصب LiteSpeed Cache

/* --- دیباگ: در تولید خاموش --- */
define('WP_DEBUG', false);
define('WP_DEBUG_LOG', false);
define('WP_DEBUG_DISPLAY', false);
@ini_set('display_errors', 0);
```

> ⚠ کلیدهای امنیتی (SALT) را از `https://api.wordpress.org/secret-key/1.1/salt/` بگیرید و جایگزین پیش‌فرض کنید.

> 💡 برای محیط staging: `WP_DEBUG=true` و `WP_DEBUG_LOG=true` و `WP_ENVIRONMENT_TYPE='staging'`.

## ۳. تنظیمات عمومی پیشخوان

### ۳.۱ تنظیمات → عمومی
| گزینه | مقدار |
|---|---|
| عنوان سایت | `امداد خودرو دلیجان \| یدک‌کش و امداد شبانه‌روزی` |
| معرفی کوتاه | `یدک‌کش، خودروبر، چرخگیر و حمل خودرو به تعمیرگاه به‌صورت 24 ساعته در دلیجان و جاده‌های اطراف` |
| نشانی وردپرس / نشانی سایت | `https://sos-delijan.ir` |
| ایمیل مدیر | ایمیل کارفرما |
| زبان | **فارسی** |
| منطقهٔ زمانی | `تهران` |
| قالب تاریخ | `Y/n/j` |
| نخستین روز هفته | شنبه |

> 📌 تنظیم زبان به فارسی باعث می‌شود **قالب هلو المنتور به‌طور خودکار RTL شود** — این کلیدی است.

### ۳.۲ تنظیمات → خواندن
| گزینه | مقدار |
|---|---|
| صفحهٔ اصلی | یک برگهٔ ثابت → «خانه» |
| برگهٔ نوشته‌ها | «مجله» |
| نمایان‌شدن در موتورهای جست‌وجو | ✅ **تیک نخورد** (فقط در staging تیک بزنید) |
| تعداد نوشته در خوراک | ۱۰ |

### ۳.۳ تنظیمات → گفت‌وگو
| گزینه | مقدار |
|---|---|
| اجازهٔ دیدگاه | ❌ **خاموش** (بدون بک‌اند → بدون بخش نظرات؛ ریسک اسپم هم صفر می‌شود) |

> اگر کارفرما نظرات را می‌خواهد: فعال + نیازمند تأیید دستی + پلاگین ضداسپم. **پیش‌فرض: خاموش.**

### ۳.۴ تنظیمات → پیوندهای یکتا (Permalinks)
```
/%postname%/          → برای برگه‌ها و نوشته‌ها
```
اما برای دسته‌بندی‌های محتوا ساختار سلسله‌مراتبی تعریف می‌شود (فایل `../04-seo/02-site-architecture.md`).

> ⚠ پس از هر تغییر در پیوندها، ریدایرکت‌های `301` بررسی شوند.

### ۳.۵ کاربران
- [ ] نام کاربری مدیر: **نه** `admin` (مثلاً `sosdelijan-admin`)
- [ ] رمز: ≥ ۲۴ کاراکتر تصادفی
- [ ] فعال‌سازی 2FA
- [ ] حذف کاربرهای غیرضروری
- [ ] پروفایل → «نام نمایشی» عمومی ≠ نام کاربری ورود

## ۴. پاک‌سازی اولیه

- [ ] حذف نوشتهٔ «سلام دنیا»
- [ ] حذف برگهٔ «برگهٔ نمونه»
- [ ] حذف دیدگاه نمونه
- [ ] حذف پلاگین‌های غیرفعال و بی‌استفاده (Hello Dolly و…)
- [ ] حذف قالب‌های غیرضروری — **نگه‌داشتن یک قالب پیش‌فرض وردپرس** به‌عنوان fallback در صورت بروز خطا (مثلاً Twenty Twenty-Four)
- [ ] خالی‌کردن سطل زباله

## ۵. فایل‌های پیکربندی ریشه

### `.htaccess` (پس از وردپرس)
قواعد کانونیکال + امنیت از `../01-domain/03-dns-and-ssl.md`.

### `robots.txt`
```
User-agent: *
Allow: /

Disallow: /wp-admin/
Allow: /wp-admin/admin-ajax.php
Disallow: /?s=
Disallow: /search/
Disallow: /staging/
Disallow: /*?replytocom=

Sitemap: https://sos-delijan.ir/sitemap_index.xml
```

### `favicon` و آیکون‌ها
- [ ] `favicon.ico` در ریشه
- [ ] Apple Touch Icon، PWA manifest (اختیاری)
- [ ] تنظیم از طریق `Site Identity` یا المنتور
