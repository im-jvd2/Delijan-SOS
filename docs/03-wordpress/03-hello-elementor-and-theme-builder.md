# قالب Hello Elementor + تم‌بیلدر المنتور پرو

---

## ۱. چرا Hello Elementor انتخاب درستی است

| ویژگی | اثر |
|---|---|
| تقریباً بدون استایل (Blank Canvas) | بدون CSS اضافی؛ هرچه هست از المنتور است |
| بدون jQuery اضافه | کاهش درخواست‌ها |
| حجم بسیار کم (~۵۰KB) | TTFB و LCP بهتر |
| پشتیبانی ذاتی RTL | با `fa_IR` خودکار راست‌به‌چپ می‌شود |
| سازگاری کامل با تم‌بیلدر | هدر/فوتر/قالب صفحه در المنتور ساخته می‌شود |

> ⚠ **پیامد:** چون قالب هیچ استایلی ندارد، **همهٔ استایل‌های پایه (تایپوگرافی، رنگ لینک، فاصله‌ها) باید در المنتور تعریف شوند**. اگر این کار نکنید، سایت «بی‌قالب» به نظر می‌رسد.

---

## ۲. تنظیمات قالب هلو

در `نمایش → Hello Theme Options`:
- [ ] حذف Hello Elementor branding از فوتر: ✅ **خاموش** (تیک «Show Hello Elementor header/footer» را غیرفعال کنید؛ چون هدر/فوتر را خودمان در تم‌بیلدر می‌سازیم)
- [ ] اگر گزینهٔ «Header/Footer» فعال بماند، **دو هدر** روی هم می‌افتند — باگ رایج

در `نمایش → سفارشی‌سازی`:
- [ ] Site Identity → لوگو، آیکون سایت
- [ ] سایر گزینه‌ها دست‌نخورده (المنتور آن‌ها را نادیده می‌گیرد)

## ۳. تنظیمات سراسری المنتور (Site Settings)

مسیر: `المنتور → تنظیمات` و داخل ویرایشگر `☰ → تنظیمات سایت`

### ۳.۱ رنگ‌های سراسری
| توکن | نام | مقدار | کاربرد |
|---|---|---|---|
| `primary` | سرمه‌ای اصلی | `#0B1F3A` | هدر، تیترها، فوتر |
| `secondary` | کهربایی | `#F5A300` | آیکون‌ها، تأکید، نوار بالا |
| `accent` | قرمز اضطراری | `#E11D2E` | دکمهٔ تماس، CTA |
| `success` | سبز | `#16A34A` | تیک‌ها، پیام موفقیت |
| `text` | متن اصلی | `#1F2937` | پاراگراف‌ها |
| `muted` | متن کم‌رنگ | `#6B7280` | توضیحات فرعی |
| `bg` | پس‌زمینه | `#FFFFFF` | — |
| `bg-alt` | پس‌زمینهٔ بخش | `#F3F4F6` | بخش‌های یک‌درمیان |

> 📐 نسبت کنتراست و قواعد دسترسی‌پذیری در `../06-design/01-design-system.md`.

### ۳.۲ تایپوگرافی سراسری
فونت: **وزیرمتن (Vazirmatn)** — بارگذاری به‌صورت Custom Font (نه Google Fonts).

| توکن | وزن | اندازه (دسکتاپ/موبایل) | ارتفاع خط | کاربرد |
|---|---|---|---|---|
| `H1` | ۸۰۰ | ۴۰ / ۲۸ px | ۱.۴ | عنوان اصلی صفحه |
| `H2` | ۷۰۰ | ۳۰ / ۲۲ px | ۱.۵ | عنوان بخش |
| `H3` | ۷۰۰ | ۲۲ / ۱۸ px | ۱.۶ | زیربخش |
| `H4` | ۵۰۰ | ۱۸ / ۱۶ px | ۱.۷ | عنوان کارت |
| `Body` | ۴۰۰ | ۱۷ / ۱۶ px | **۱.۹** | پاراگراف |
| `Small` | ۴۰۰ | ۱۴ / ۱۳ px | ۱.۷ | توضیحات فرعی |
| `Button` | ۷۰۰ | ۱۷ / ۱۶ px | ۱.۴ | دکمه‌ها |

> 💡 **ارتفاع خط ۱.۹ برای متن فارسی** حیاتی است. خطوط فارسی (با کلمات بلند و چسبیده) با ارتفاع خط ۱.۵ ناخوانا می‌شوند.

### ۳.۳ چیدمان
| گزینه | مقدار |
|---|---|
| عرض محتوای صندوق | ۱۱۴۰ px |
| عرض محتوای ویجت | ۷۶۰ px |
| فاصلهٔ پیش‌فرض | ۲۰ px |
| جهت | راست‌به‌چپ (خودکار از زبان سایت) |

### ۳.۴ نقاط شکست (Breakpoints)
| نقطه | حداکثر عرض |
|---|---|
| موبایل | ۷۶۷ px |
| موبایل بزرگ (اختیاری) | ۸۸۰ px |
| تبلت | ۱۰۲۴ px |
| لپ‌تاپ | ۱۳۶۶ px |
| دسکتاپ | بزرگ‌تر |

> ⚠ در تنظیمات المنتور: `تنظیمات → پیشرفته → نقاط شکست فعال` → افزودن «لپ‌تاپ».

## ۴. تم‌بیلدر — قالب‌های لازم

مسیر: `المنتور → تم‌بیلدر`

| # | نوع قالب | نام | شرط نمایش | اولویت |
|---|---|---|---|---|
| 1 | **Header** | `H-Main` | کل سایت | P1 |
| 2 | **Header** | `H-Sticky-Mobile` | فقط موبایل (اگر جدا ساخته شود) | P2 |
| 3 | **Footer** | `F-Main` | کل سایت | P1 |
| 4 | **Single Page** | `P-Default` | همهٔ برگه‌ها | P1 |
| 5 | **Single Page** | `P-Service` | برگه‌های زیرمجموعهٔ `/خدمات/` | P1 |
| 6 | **Single Page** | `P-City` | برگه‌های زیرمجموعهٔ `/مناطق/` | P1 |
| 7 | **Single Page** | `P-Road` | برگه‌های زیرمجموعهٔ `/جاده/` | P2 |
| 8 | **Single Post** | `S-Post` | همهٔ نوشته‌ها | P2 |
| 9 | **Archive** | `A-Blog` | آرشیو `/مجله/` | P3 |
| 10 | **404** | `E-404` | خطای ۴۰۴ | P2 |
| 11 | **Search Results** | `A-Search` | نتایج جست‌وجو | P3 |
| 12 | **Popup** | `POP-Call` | خروج کاربر / بعد از ۳۰ ثانیه (موبایل) | P3 |
| 13 | **Popup** | `POP-Exit` | خروج از سایت (دسکتاپ) | P3 |

> ⚠ **قاعده:** هر چه تعداد قالب‌های تم‌بیلدر کمتر، سایت سریع‌تر. قالب‌های P-Service / P-City / P-Road را فقط در صورت تفاوت معنادار جدا بسازید؛ در غیر این صورت از `P-Default` با بخش‌های شرطی استفاده کنید.

## ۵. آناتومی هدر (`H-Main`)

```
┌───────────────────────────────────────────────────────────────┐
│ نوار بالا (کهربایی): ☎ 0910 050 4113  •  ۲۴ ساعته، ۷ روز هفته │
├───────────────────────────────────────────────────────────────┤
│  [لوگو]        منو: خانه | خدمات | مناطق | جاده‌ها | مجله      │
│                                              [📞 تماس فوری]   │
└───────────────────────────────────────────────────────────────┘
```

**مشخصات فنی:**
| ویژگی | مقدار |
|---|---|
| حالت چسبنده (Sticky) | فقط در موبایل (کاهش فضای عمودی در دسکتاپ) |
| ارتفاع | دسکتاپ ۷۲px، موبایل ۶۰px |
| لوگو | SVG ترجیحاً؛ حداکثر ۲۰۰×۶۰px |
| منو | حداکثر ۶ آیتم؛ بدون مگامنو (سنگین است) |
| دکمهٔ CTA | رنگ `accent`، متن «تماس فوری»، لینک `tel:` |
| منوی موبایل | Off-Canvas از سمت راست |

> ⚠ **دکمهٔ تماس در هدر باید `tel:` باشد نه اسکرول به بخش تماس.** کاربر در جاده است؛ یک لمس = تماس.

## ۶. آناتومی فوتر (`F-Main`)

```
┌───────────────────────────────────────────────────────────────┐
│ ستون ۱: لوگو + توضیح کوتاه + ساعات کاری                       │
│ ستون ۲: خدمات (۶ لینک)      ستون ۳: مناطق (۸ لینک + «همه»)   │
│ ستون ۴: تماس (فقط تلفن + ساعت)                              │
├───────────────────────────────────────────────────────────────┤
│ نوار پایانی: © ۱۴۰۵ … | حریم خصوصی | قوانین                  │
└───────────────────────────────────────────────────────────────┘
```

> ⚠ **فوتر را با لینک شهری پر نکنید.** حداکثر ۸ تا ۱۰ لینک + لینک «همهٔ مناطق». فوتر با ۵۰ لینک = سیگنال اسپم + افت سرعت رندر.

## ۷. نوار اکشن موبایل (Mobile Action Bar)

یک عنصر ثابت پایین صفحه **فقط در موبایل**:

```
┌─────────────────────────────────────┐
│           📞  تماس فوری  0910 050 4113           │
└─────────────────────────────────────┘
```

- ارتفاع ۵۶px، پس‌زمینه `primary`/`accent`
- `position: fixed; bottom: 0`
- `padding-bottom` روی `body` تا محتوا زیر آن نرود
- در دسکتاپ مخفی

## ۸. تنظیمات عملکرد المنتور (الزامی)

مسیر: `المنتور → تنظیمات → پیشرفته`

| گزینه | مقدار | دلیل |
|---|---|---|
| **CSS Print Method** | External File | یک فایل کش‌شدنی به‌جای inline |
| **Improved CSS Loading** | ✅ فعال | حذف CSS ویجت‌های استفاده‌نشده |
| **Improved Asset Loading** | ✅ فعال | بارگذاری شرطی JS |
| **Font Awesome Loading** | SVG | حذف فونت سنگین |
| **Google Fonts Load** | ❌ خاموش | فونت محلی وزیرمتن استفاده می‌شود |
| **Flexbox Container** | ✅ فعال (پیش‌فرض نسخه‌های جدید) | ساختار DOM سبک‌تر از Section/Column |
| **Element Caching** | ✅ فعال | کاهش زمان رندر |
| **Unfiltered File Uploads** | ❌ خاموش | امنیت |
| **Disable Default Colors/Fonts** | ✅ فعال | جلوگیری از تداخل با توکن‌های سایت |

## ۹. قاعدهٔ استفاده از ویجت‌ها

| ✅ استفاده شود | ❌ پرهیز شود |
|---|---|
| Container (Flexbox) | Section + Column قدیمی |
| Heading, Text Editor | Inner Section |
| Icon Box, Icon List | Slider/Carousel (به‌جز یک مورد) |
| Image (با ابعاد صریح) | Video پس‌زمینه |
| Accordion (برای FAQ) | Tabs با محتوای سنگین |
| Button, Icon | Form سنگین با اعتبارسنجی زیاد |
| HTML (برای JSON-LD) | Counter با انیمیشن سنگین |
| Divider, Spacer | — |

## ۱۰. چک‌لیست پذیرش

- [ ] فقط یک هدر و یک فوتر رندر می‌شود (نه دوتا)
- [ ] همهٔ رنگ‌ها از توکن‌های سراسری انتخاب شده‌اند (بدون هگز دستی در ویجت‌ها)
- [ ] همهٔ فونت‌ها از توکن‌های تایپوگرافی سراسری
- [ ] قالب ۴۰۴ سفارشی ساخته شده و لینک به صفحهٔ اصلی و تماس دارد
- [ ] نوار اکشن موبایل در ۳۶۰px درست نمایش داده می‌شود و روی محتوا نمی‌افتد
- [ ] منوی موبایل با یک لمس باز می‌شود و `aria-expanded` درست تنظیم است
- [ ] تست روی ۳ عرض: ۳۶۰px، ۷۶۸px، ۱۳۶۶px — بدون سرریز افقی
- [ ] هیچ اسکریپت Google Fonts بارگذاری نمی‌شود
