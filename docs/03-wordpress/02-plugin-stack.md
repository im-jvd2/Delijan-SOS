# پشتهٔ پلاگین‌ها (Plugin Stack)

> **اصل حاکم:** هر پلاگین یک بدهی عملکردی است. سقف مجاز: **۱۵ پلاگین فعال**.
> پیش از افزودن هر پلاگین، سؤال «آیا با کد یا تنظیمات خودِ وردپرس/المنتور حل نمی‌شود؟» پرسیده شود.

## ۲. پلاگین‌های اختیاری (فقط در صورت نیاز واقعی)

| پلاگین | چه زمانی لازم است | جایگزین سبک‌تر |
|---|---|---|
| **WP Cerber Security** یا **Wordfence** | اگر سایت هدف حملهٔ مکرر است | `Limit Login Attempts Reloaded` تنها |
| **Loco Translate** | اگر نیاز به ترجمهٔ رشته‌های قالب/پلاگین است | فایل `.po` دستی |
| **WPCode / Insert Headers and Footers** | برای تزریق JSON-LD یا GTM | ویجت HTML المنتور |
| **Contact Form 7** | فقط اگر کارفرما فرم تماس خواست | دکمهٔ `tel:` (پیشنهاد D-007) |
| **WP-Optimize** | اگر دیتابیس سنگین شد | دستور WP-CLI |
| **Perfmatters** | برای کنترل دقیق assetها | تنظیمات خود LSCache |
| **Rank Math Local SEO** | برای NAP و اسکیمای محلی پیشرفته | JSON-LD دستی در ویجت HTML |
| **Google Site Kit** | اگر کارفرما داشبورد GA4 در پیشخوان بخواهد | نصب دستی GA4 |

## ۳. پلاگین‌های ممنوع (Blacklist)

| پلاگین | دلیل |
|---|---|
| هر پلاگین **nulled / کرک‌شده** | بدافزار، عدم به‌روزرسانی، ریسک حقوقی |
| اسلایدرهای سنگین (Slider Revolution) | فاجعهٔ Core Web Vitals |
| Jetpack (کامل) | حجم بالا؛ ماژول‌هایش با ابزارهای موجود پوشش داده می‌شود |
| WPML / Polylang | سایت تک‌زبانه است |
| ووکامرس | فروشگاه نداریم |
| هر پلاگین «All-in-One SEO Suite» دوم | تداخل اسکیم‌ها و متا |
| پلاگین‌های «بهینه‌ساز دیتابیس + کش + امنیت» هم‌زمان | تداخل؛ یکی انتخاب شود |
| پلاگین‌های نمایش «آخرین بازدید»/آمار در پیشخوان | بار اضافه بدون ارزش |

## ۴. مسئلهٔ لایسنس المنتور پرو

| گزینه | مزیت | عیب | توصیه |
|---|---|---|---|
| **لایسنس اصلی از `elementor.com`** (~۵۹ دلار/سال برای Essential) | پشتیبانی رسمی، به‌روزرسانی مطمئن | پرداخت ارزی | ✅ اگر ممکن باشد، بهترین |
| **خرید از مارکت‌پلیس ایرانی** (ژاکت / راست‌چین) | پرداخت ریالی، پشتیبانی فارسی، به‌روزرسانی | لایسنس اشتراکی، وابسته به فروشنده | ✅ گزینهٔ عملی رایج در ایران |
| **نسخهٔ nulled / رایگان غیررسمی** | رایگان | ❌ بدافزار، بدون به‌روزرسانی امنیتی، ریسک جدی | ❌ **ممنوع** (X-003) |

> ⚠ **هشدار جدی:** سایت‌های امداد خودرو هدف جذابی برای بدافزار هستند (ترافیک بالا، کاربران در حال تماس). نصب نسخهٔ nulled می‌تواند منجر به تزریق کد، ریدایرکت به سایت‌های شرط‌بندی و **حذف کامل از گوگل** شود. این یک ریسک تجاری است، نه فنی.

## ۵. پیکربندی پلاگین‌های کلیدی

### ۵.۱ Rank Math SEO
**ماژول‌های فعال (فقط این‌ها):**
- ✅ Sitemap
- ✅ SEO Analysis
- ✅ Schema (Structured Data)
- ✅ 404 Monitor + Redirections
- ✅ Local SEO (اگر نصب شد)
- ❌ WooCommerce، bbPress، BuddyPress، AMP، News، Video، Image SEO (ماژول‌های سنگین بی‌کاربرد)

**تنظیمات:**
| بخش | مقدار |
|---|---|
| Titles & Meta → Homepage | طبق `../04-seo/03-on-page-standard.md` |
| Search Appearance → Separator | ` \| ` |
| Sitemap → Include | فقط برگه‌ها، نوشته‌ها، دسته‌بندی‌های اصلی |
| Sitemap → Exclude | تگ‌ها، صفحات utility، برگه‌های محرمانه |
| Others → Noindex | صفحهٔ جست‌وجو، آرشیو نویسنده، صفحهٔ برچسب |
| Breadcrumbs | فعال، جداکننده `›` |
| IndexNow | فعال (برای Bing/Yandex) |

### ۵.۲ LiteSpeed Cache
| بخش | مقدار |
|---|---|
| Cache → Enable Cache | ✅ |
| Cache → Cache Logged-in Users | ❌ (سایت عمومی است) |
| TTL → Public Cache | ۶۰۴۸۰۰ (۷ روز) |
| Purge → Purge All on Upgrade | ✅ |
| Optimize → CSS/JS Minify | ✅ |
| Optimize → Load CSS Asynchronously | ⚠ با احتیاط (ریسک FOUC) — فقط با Critical CSS |
| Optimize → Combine CSS/JS | ⚠ تست شود؛ گاهی نتیجهٔ معکوس می‌دهد |
| Optimize → Remove jQuery Migrate | ✅ |
| Optimize → Load JS Deferred | ✅ (`Delayed` نه — ریسک شکستن المنتور) |
| Image → Image Optimization | ✅ + ارسال WebP |
| Image → WebP Replacement | ✅ |
| Page Optimize → Lazy Load Images | ✅ + **استثنا برای تصویر بالای صفحه (LCP)** |
| Database | هفته‌ای یکبار پاک‌سازی |
| Crawler | فعال با احتیاط (بار سرور) |

> ⚠ **قاعدهٔ طلایی:** هر بار فقط **یک** تغییر در تنظیمات بهینه‌سازی اعمال شود و سپس PageSpeed دوباره اندازه‌گیری شود. ترکیب چند تغییر، ریشه‌یابی را غیرممکن می‌کند.

### ۵.۳ UpdraftPlus

|---|---|
