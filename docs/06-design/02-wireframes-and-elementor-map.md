## ۲. نگاشت بخش‌ها به ویجت‌های المنتور

| بخش | ویجت‌های المنتور | نوع ظرف | یادداشت |
|---|---|---|---|
| S1 نوار بالا | Container + Text + Button(link) | Flex, full-width | ارتفاع ۳۶px موبایل، ۴۰px دسکتاپ |
| S2 هدر | **تم‌بیلدر Header** — Container + Site Logo + Nav Menu + Button | Flex, space-between | Sticky فقط موبایل |
| S3 Hero | Container + Heading + Text Editor + Button ×۲ + Icon List | Flex, ۲ ستون دسکتاپ | تصویر LCP → بدون lazy |
| S4 خدمات | Container + **Icon Box** ×۸ (یا Loop Grid) | CSS Grid, ۲/۴ ستون | کل کارت کلیک‌پذیر |
| S5 مزیت‌ها | Container + Icon List | Flex, ۱ ستون | آیکون SVG کهربایی |
| S6 باکس اعتماد | Container + **Counter** یا Heading+Text | CSS Grid, ۳ ستون | ⚠ Counter با انیمیشن → `prefers-reduced-motion` |
| S7 جاده‌ها | Container + **Icon Box** ×۴ یا Post Grid | CSS Grid, ۳ ستون | — |
| S8 مناطق | Container + Button (لینک) ×۸ | Flex wrap | دکمه‌های کوچک، نه متن ساده |
| S9 هزینه | Container + **Icon List** (عوامل هزینه) + Button | Flex, ۲ ستون | ⛔ **بدون جدول قیمت** (D-016) — فقط عوامل مؤثر + CTA تماس |
| S10 تعهدات ما | Container + **Icon List** ×۴ (Icon Box) | CSS Grid, ۲/۴ ستون | ⛔ **Testimonial Carousel نصب نشود** (D-017). پس از جمع‌آوری نظر واقعی، همین بلوک جایگزین می‌شود |
| S11 FAQ | Container + **Accordion** | — | + JSON-LD در ویجت HTML |
| S12 تماس | Container + Image (نقشهٔ **محدودهٔ پوشش**) + Icon List + Button | Flex, ۲ ستون | تصویر نقشه lazy · ⛔ **بدون پین آدرس، بدون ایمیل** (Q-07) |
| S13 فوتر | **تم‌بیلدر Footer** | CSS Grid, ۴ ستون | — |
| نوار موبایل | Container + Button ×۲ (شرط: موبایل) | Fixed position | در تم‌بیلدر یا ویجت سراسری |

## ۸. پروتوتایپ HTML (فاز ۲)

در فاز ۲، یک پروتوتایپ ایستا در این ریپو ساخته می‌شود:

```
prototype/
├── index.html
├── service.html
├── city.html
├── road.html
├── blog.html
├── assets/
│   ├── css/main.css
│   ├── css/tokens.css
│   └── fonts/
└── README.md
```

**الزامات پروتوتایپ:**
- HTML معنایی (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`)
- CSS خالص (بدون فریم‌ورک) با متغیرهای `01-design-system.md`
- RTL کامل
- تست روی ۳۶۰px، ۷۶۸px، ۱۳۶۶px
- Lighthouse ≥ ۹۵ در همهٔ معیارها
- بدون JavaScript مگر برای آکاردئون و منوی موبایل
- قابل بازبینی توسط کارفرما پیش از پیاده‌سازی در المنتور
