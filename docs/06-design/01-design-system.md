# سیستم طراحی (Design System)

> **اصل:** کاربر ما در شرایط استرس است، با موبایل، زیر نور آفتاب یا در تاریکی شب.

### ۲.۴ قواعد
- حداکثر ۴ وزن فونت
- حداکثر ۶ سطح اندازه
- ❌ هیچ متنی زیر ۱۴px

- ✅ **ارقام لاتین `0123456789` در همه‌جا** — این خط قبلاً «ارقام فارسی در متن» بود و **باطل شد** (پاسخ Q-32 / D-010)

#### ۲.۴.۱ رندر ارقام لاتین در متن راست‌به‌چپ

وزیرمتن ارقام لاتین را با کیفیت در متن فارسی رندر می‌کند، اما برای جلوگیری از جهش جهت در رشته‌های مخلوط (مثل `10 تا 20 دقیقه` یا `0910 050 4113`) این قواعد CSS الزامی است:

```css
/* ارقام همیشه لاتین بمانند، حتی در متن RTL */
:root { font-variant-numeric: lining-nums; }

body, .e-con { font-feature-settings: "lnum" 1; }

/* شمارهٔ تماس و اعداد مسیر: جهت‌دهی صریح برای جلوگیری از به‌هم‌ریختگی */
.num, a[href^="tel:"], .distance, .duration, .price, .table-local td:nth-child(2) {
  direction: ltr;
  unicode-bidi: embed;
  font-variant-numeric: tabular-nums lining-nums;
}

/* جداکنندهٔ هزارگان با ویرگول لاتین، در سمت راستِ رقمِ راست */
.num { font-feature-settings: "lnum" 1; white-space: nowrap; }
```

| قاعده | درست ✅ | غلط ❌ |
|---|---|---|
| همهٔ ارقام لاتین | `92 کیلومتر` | `۹۲ کیلومتر` |
| شمارهٔ تماس با فاصلهٔ خوانا | `0910 050 4113` | `09100504113` |
| بازهٔ زمان | `10 تا 20 دقیقه` | `۱۰-۲۰ دقیقه` |
| سال | `1405` | `۱۴۰۵` |
| جداکنندهٔ هزارگان | `1,800,000 ریال` | `۱٫۸۰۰٫۰۰۰` |

- ⛔ **هیچ افزونهٔ تبدیل ارقام نصب نشود** (Persian Number و مشابه) — در بلک‌لیست پلاگین‌هاست.
- ⛔ در Elementor، ویجت Counter و ویجت تاریخ شمسی به‌صورت پیش‌فرض رقم فارسی می‌دهند؛ در تنظیمات هر دو، فرمت عدد/تاریخ روی حالت لاتین گذاشته شود یا از ویجت Heading با متن ثابت استفاده شود.
- ✅ بررسی پایانی: `grep -rnP '[۰-۹٠-٩]'` روی خروجی HTML صفحه باید **خالی** باشد.

### ۴.۸ بلوک «تعهدات ما» — جایگزین بخش نظرات مشتریان (D-017)

> ⛔ **ویجت Testimonial Carousel المنتور در هیچ صفحه‌ای نصب نشود.** کارفرما تا زمان نگارش این سند هیچ نظر واقعی از مشتری ندارد و ساخت نظر جعلی رد شد (X-006). همان جای صفحه به بلوک «تعهدات ما» اختصاص می‌یابد.

| ویژگی | مقدار |
|---|---|
| چیدمان | CSS Grid، ۴ ستون در دسکتاپ / ۲ ستون در تبلت / ۱ ستون در موبایل |
| پس‌زمینه | `--c-bg-alt` (`#F3F4F6`) برای تفکیک از بدنه |
| آیتم | آیکون تیک SVG (`--c-success`) + متن کوتاه حداکثر ۶ کلمه |
| عنوان بخش | «تعهدات ما» — `h2`، ۲۸px، وزن ۷۰۰ |
| ارتفاع | حداقل `120px` در هر آیتم؛ `gap: 24px` |
| انیمیشن | هیچ — فقط `:hover` با تغییر `background` به `--c-primary-100` |

**چهار تعهد ثابت (قابل اثبات، برگرفته از پاسخ کارفرما):**
1. پاسخ‌گویی 24 ساعته، 7 روز هفته
2. اعلام زمان و هزینه پیش از اعزام
3. بیش از 5 سال تجربه در دلیجان و جاده‌های اطراف
4. حمل با نیسان یدک‌کش، چرخگیر و کفی خودروبر

**ارتقای آینده:** پس از جمع‌آوری نظر واقعی (پیامک پس از خدمت / کیوآرکد داخل خودرو / درخواست راننده)، این بلوک با کاروسل نظرات واقعی جایگزین می‌شود و اسکیمای `aggregateRating` هم‌زمان اضافه می‌گردد. **تا آن زمان نه بلوک نظرات ساخته می‌شود نه اسکیمای امتیاز.**

## ۷. نکات RTL

| موضوع | راه‌حل |
|---|---|
| جهت | `dir="rtl"` روی `<html>` |
| خواص منطقی | `margin-inline-start` به‌جای `margin-right` |
| فاصله | `inset-inline` به‌جای `left/right` |
| فلش/آیکون جهت‌دار | SVG جدا برای RTL (یا `transform: scaleX(-1)`) |
