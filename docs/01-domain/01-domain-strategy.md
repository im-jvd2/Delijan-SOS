## ۳. پیشنهاد نهایی

### ✅ هر دو دامنه خریداری شود؛ نقش‌ها تفکیک شود

| دامنه | نقش | رفتار |
|---|---|---|
| **`sos-delijan.ir`** | دامنهٔ رسمی (Canonical) | سایت روی آن سرو می‌شود |
| **`emdadkhodrodelijan.ir`** | دامنهٔ کمکی/دفاعی | `301` دائمی به `https://sos-delijan.ir/` (حفظ مسیر) |

### چرا هر دو؟
1. **هزینهٔ ناچیز:** نرخ رسمی ایرنیک برای هر دامنهٔ `.ir` حدود ۶۰٬۰۰۰ تومان در سال است (منبع: `02-irnic-registration-sop.md`). هزینهٔ کل کمتر از یک ساعت کار است.
2. **جذب ترافیک تایپی:** بخشی از کاربران واقعاً `emdadkhodrodelijan.ir` را تایپ می‌کنند؛ با `301` این ترافیک به ما می‌رسد به‌جای اینکه به رقیب برسد.
3. **دفاع برند:** جلوگیری از ثبت توسط رقیب.
4. **انعطاف:** اگر بعداً داده نشان داد دامنهٔ کلیدواژه‌ای CTR بهتری دارد، تغییر کانونیکال ساده است.

### اگر فقط یک دامنه خریداری می‌شود
→ **`sos-delijan.ir`**. دلیل اصلی: ریسک اشتباه‌گرفتن `emdadkhodrodelijan.ir` با دامنهٔ رقیب. در یک کسب‌وکار اضطراری، حتی ۱٪ ترافیک گم‌شده یعنی مشتری از دست رفته.

### اگر کارفرما اصرار بر دامنهٔ کلیدواژه‌ای دارد
→ `emdadkhodrodelijan.ir` قابل قبول است و **رتبه را از دست نمی‌دهد**؛ در آن صورت این اقدامات الزامی می‌شود:
- ثبت `sos-delijan.ir` هم به‌عنوان ریدایرکت
- استفاده از لوگو/برند قوی و متمایز برای جلوگیری از سردرگمی
- پایش CTR در Search Console برای مقایسه

## ۵. سیاست دامنهٔ رسمی (Canonical Host Policy)

این سیاست باید **بدون استثنا** در کل پروژه رعایت شود:

| قاعده | مقدار |
|---|---|
| پروتکل | `https://` فقط |
| هاست رسمی | `sos-delijan.ir` (بدون `www`) |
| `www.sos-delijan.ir` | `301` → `https://sos-delijan.ir/` |
| `http://*` | `301` → `https://sos-delijan.ir/...` |
| اسلش انتهایی | **با** اسلش: `https://sos-delijan.ir/مناطق/نراق/` |
| بزرگ‌و‌کوچکی | همه lowercase |
| دامنه‌های فرعی | فقط `staging.` (با Basic Auth) — هیچ زیردامنهٔ محتوایی ساخته نمی‌شود |

پیاده‌سازی فنی در `03-dns-and-ssl.md`.

## ۶. نام تجاری در برابر دامنه

پیشنهاد ساختار برند دو لایه:

```
برند اصلی:  SOS دلیجان           ← لوگو، هدر، حافظهٔ کاربر
نام توصیفی: امداد خودرو دلیجان   ← تایتل‌تگ، H1، اسکیم‌ها، لنگرها
```

مثال تایتل صفحهٔ اصلی:

```
امداد خودرو دلیجان | یدک‌کش، خودروبر و حمل به تعمیرگاه شبانه‌روزی — SOS دلیجان
```

این کار هم کلیدواژه را در ابتدای تایتل نگه می‌دارد و هم برند را می‌سازد.
